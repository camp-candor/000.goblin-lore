## 3. Concrete Implementation Specifications

### Task 3.1: Integer Agenda Offset Calculator (`05.clock.unit/buz/clock.buzz.ts`)

1. `computeAgendaBeatTickOffset(chronology, beat)`:
   - Origin epoch seconds = `computeGregorianEpochSeconds(chronology.start_date, normalizeClockTimeHms(chronology.start_time))`.
   - Target epoch seconds = `computeGregorianEpochSeconds(beat.isoDate, normalizeClockTimeHms(beat.startTimeHm))`.
   - `deltaSeconds = targetEpoch - originEpoch`.
   - If `!beat.recurringDaily && deltaSeconds < 0`, return `{ valid: false, errorCode: 'AGENDA_IN_THE_PAST', deltaSeconds, targetTick: -1 }`.
   - `targetTick = Math.ceil(Math.max(0, deltaSeconds) / chronology.tick_seconds)`.
   - `reserveStartTick = Math.max(0, targetTick - beat.reserveCooldownTicks)`.
2. `validateChronoAgendaRegistry(chronology)` sorts resolved entries by `targetTick`, detects reserve window intersections (`reserveStartTick[next] <= targetTick[prev]`), and returns `{ valid, errors, resolvedBeats, overlaps }`.

### Task 3.2: Reserve Cooldown Blocker (`06.cooldown.unit/buz/cooldown.buzz.ts`)

- `evaluateAgendaReserveBlock(currentTick, resolvedBeats)` checks whether any beat satisfies `currentTick >= beat.reserveStartTick && currentTick < beat.targetTick`. If so, returns `{ heldByReserve: true, beatId: beat.beat_id, beatCategory: beat.beatCategory, ticksUntilBeat: beat.targetTick - currentTick }`.
