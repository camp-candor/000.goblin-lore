## 3. Concrete Implementation Specifications

### Task 3.1: `06.cooldown.unit` Scene Spacing Helpers

- `evaluateGlobalSceneCooldown(ticksSinceLastScene, minutesSinceLastScene, severityBps, pacing)`:
  - If `ticksSinceLastScene === null` (first scene in run), `{ blocked: false, reason: 'FIRST_SCENE' }`.
  - If `ticksSinceLastScene < pacing.min_ticks_between_scenes || (pacing.min_minutes_between_scenes > 0 && minutesSinceLastScene < pacing.min_minutes_between_scenes)`:
    - If `severityBps >= pacing.critical_override_bps`: `{ blocked: false, overrideApplied: true, reason: 'CRITICAL_OVERRIDE' }`.
    - Else: `{ blocked: true, overrideApplied: false, remainingTicks: Math.max(0, pacing.min_ticks_between_scenes - ticksSinceLastScene), reason: 'COOLDOWN_ACTIVE' }`.
- `computeDroughtPressureBoostBps(ticksSinceLastScene, pacing)`:
  - If `ticksSinceLastScene === null || ticksSinceLastScene < pacing.max_dry_spell_ticks` -> `0`.
  - Excess ticks = `ticksSinceLastScene - pacing.max_dry_spell_ticks + 1`.
  - Return `Math.min(pacing.max_drought_boost_bps, excessTicks * pacing.drought_boost_bps_per_tick)`.

### Task 3.2: `10.escalation.unit` / `42.catalyst.unit` Curve Evaluation

- `resolveNarrativeActStage(progressBps, pacing)`:
  - Returns `'ACT_I'` if `progressBps <= pacing.act_i_end_bps`, `'ACT_II'` if `<= pacing.act_ii_end_bps`, else `'ACT_III'`.
- `computeThreeActPacingMultiplierBps(stage, daypart, pacing)`:
  - Selects `act_i_multiplier_bps`, `act_ii_multiplier_bps`, or `act_iii_multiplier_bps`.
  - Combines with `pacing.diurnal_tension_weights_bps[daypart]` using `Number((BigInt(actMult) * BigInt(diurnalMult)) / 10000n)`.
- `evaluateCatalystWithPacingBudget(config, input)` returns frozen `PacingCatalystVerdict`.
