## 3. Concrete Implementation Specifications

### Task 3.1: Weekday, Lunar, Solar, Horizon Expansion (`05.clock.unit/buz/clock.buzz.ts`)

- `resolveGregorianWeekday(isoDate: string): WeekdayToken`:
  - Validate `isoDate` via `isValidGregorianIsoDate` (throw `[INVALID_AGENDA_DATE]` on failure).
  - Compute day of week via Tomohiko Sakamoto's table `[0, 3, 2, 5, 0, 3, 5, 1, 4, 6, 2, 4]` and map `0 -> 'SUN', 1 -> 'MON', 2 -> 'TUE', 3 -> 'WED', 4 -> 'THU', 5 -> 'FRI', 6 -> 'SAT'`.
- `computeSynodicLunarPhase(isoDate: string, startTimeHm = '00:00'): LunarPhaseSnapshot`:
  - Compute UTC epoch seconds `epochSec` from `(isoDate, startTimeHm)`.
  - `SYNODIC_MONTH_SECONDS = 2551443`, `REF_NEW_MOON_SEC = 947182440` (`2000-01-06T18:14:00Z`).
  - `ageSeconds = (((epochSec - REF_NEW_MOON_SEC) % SYNODIC_MONTH_SECONDS) + SYNODIC_MONTH_SECONDS) % SYNODIC_MONTH_SECONDS`.
  - `cycleProgressBps = Math.floor((ageSeconds * 10000) / SYNODIC_MONTH_SECONDS)`.
  - Map `cycleProgressBps` to 4 phase windows (`NEW_MOON`: `0..1249` or `8750..10000`, `FIRST_QUARTER`: `1250..3749`, `FULL_MOON`: `3750..6249`, `LAST_QUARTER`: `6250..8749`) and triangle-wave `illuminationBps` (`0..10000`, peaking at `10000` at `cycleProgressBps === 5000`).
- `expandRecurrenceOccurrencesInHorizon(chronology, horizonDays = 14)`:
  - Iterates day `d = 0..horizonDays` from `chronology.startDate`, evaluates each beat's normalized `recurrenceRule`, checks blackout sets (`beat.recurrenceRule.blackoutDates`, `beat.recurrenceRule.blackoutWeekdays`, `chronology.series_blackout_dates`), applies `SKIP` or `DEFER_NEXT_VALID_DAY`, respects `untilIsoDate` and `maxOccurrences`, and computes `targetTick` and `reserveStartTick`.
