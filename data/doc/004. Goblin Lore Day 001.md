### Pass 3: Deterministic Sealing, RFC 8785 Canonicalization, and Dual-Emission Persistence

#### Unicode Normalization Form C (NFC) and POSIX Line Endings

All string values across the entire state payload are processed through Unicode Normalization Form C (NFC). This eliminates visual-equivalence hash drift, where identical characters represented via distinct composite or pre-composed code points produce divergent cryptographic hashes. Furthermore, all text payloads are conformed strictly to POSIX line-feed (`\n`) delimiters, stripping Windows CRLF carriage returns.

#### Universal SHA-256 Merkle State Sealing

The canonical, sorted, NFC-normalized byte stream is serialized and passed through a cryptographic SHA-256 hashing engine. This produces a single, immutable 64-character hexadecimal Merkle root state hash ($H_{\text{root}}$):

$$

In addition to the global root hash, the compiler derives individual SHA-256 content hashes for every constituent entity ($H_{\text{entity}}$). These individual digests construct a dependency graph that powers fine-grained cache invalidation on edge workers, ensuring that downstream systems recompile only the exact branches of the narrative graph affected by a modified entity.

1. The serialized JSON payload is written to an ephemeral sibling scratchpad file located strictly within the same directory mount point (e.g., a temporary file using a distinct execution identifier).

#### 2. `compile.reduce.ts`

Pure state reduction using `clone-deep`, maintaining single-direction state mutation:

```typescript
import clone from "clone-deep";
import * as Act from "./compile.action";
import { CompileModel } from "./compile.model";
import * as Buzz from "./compile.buzzer";
import State from "../99.core/state";

export function reducer(
  model: CompileModel = new CompileModel(),
  act: Act.Actions,
  state?: State
): CompileModel {
  switch (act.type) {
    case Act.INIT_COMPILE:
      return Buzz.initCompile(clone(model), act.bale, state);

    case Act.RUN_COMPILE:
      return Buzz.runCompile(clone(model), act.bale, state);

    case Act.PASS1_EVALUATE:
      return Buzz.pass1Evaluate(clone(model), act.bale, state);

    case Act.PASS2_TRAVERSE:
      return Buzz.pass2Traverse(clone(model), act.bale, state);

    case Act.PASS3_SEAL:
      return Buzz.pass3Seal(clone(model), act.bale, state);

    case Act.GATE0_VERIFY:
      return Buzz.gate0Verify(clone(model), act.bale, state);

    default:
      return model;
  }
}
```

- `compile.model.ts` sets default state values (`status: "IDLE"`, initialized arrays and sets).
- `compile.buzzer.ts` exposes all execution handlers exported from `buz/compile.buzz.ts`.

### Phase 3: The Engine Implementation (`buz/compile.buzz.ts`)

`buz/compile.buzz.ts` orchestrates the file system checks, schema parsing, graph traversal, and serialization.

#### Ingress Sweep & Pass 1: Structural Bounds & Physical Sentinels

1. **Byte-0 Frontmatter Law**: Enforces that physical byte index 0 of every `.md` file is strictly `---`. Files with leading blank lines, spaces, or UTF-8 BOM markers immediately fail closed.
2. **Zero-Byte Poison Sentinel**: Compares file SHA-256 hashes against `e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855` and traps unhydrated Git LFS pointer stubs (<1,024 bytes).
3. **Pure 7-Bit ASCII Compliance**: Rejects multi-byte UTF-8 emojis and special graphical runes to prevent cursor desynchronization and crashes in curses terminal displays.
4. **Zod Closed Contracts (`.strict()`)**: Evaluates frontmatter properties against Zod schemas, forbidding unindexed or undeclared properties (`additionalProperties: false`).
5. **Basis-Point Normalization & Banker's Rounding**: Rejects IEEE-754 floats; all probabilities, ratios, and condition levels must be integers between $0$ and $10{,}000\text{ bp}$, using round-half-even ties.
6. **Somatic SAT Invariant**: Evaluates character equipment loadouts against anatomical limb constraints:
  $$
  \sum \text{occupies\_hands} \le \text{available\_arms}
  $$
  Actors cannot wield more gear than they have functional limbs.
7. **Banned Kinetic Verb Masks**: Confirms that characters suffering physical trauma do not contain baseline actions that violate their active motor impairment masks.

#### Pass 2: Relational Topology & Graph Acyclicity

1. **Foreign-Key Closure Sweep**: Builds an in-memory index of all entity identifiers (characters, locations, possessions, grievances). Ensures every item in `logistical.held`, every target in `participants_primary`, and every spatial link points to an active dossier. Any dangling pointer halts execution.
2. **Three-Color Depth-First Search (DFS) Cycle Detection**: Models grievance escalation chains (`spawns_on_max_escalation`) as a Directed Graph:
  - `WHITE (0)`: Unvisited node.
  - `GRAY (1)`: Node currently on the active recursion stack.
  - `BLACK (2)`: Fully explored, verified acyclic subtree.
  - Traversal discovering an edge leading to a `GRAY` node flags a back-edge ($A \to B \to A$) and aborts immediately with a cyclic escalation error.
3. **Bidirectional Spatial Reciprocity**: Confirms that room portals have reciprocal return vectors unless explicitly marked as a one-way path.
4. **Clue-Lemma Disjointness Theorem**: Audits the narrative's unsolved secrets, asserting that permitted environmental clue tokens ($P_{\text{clues}}$) and forbidden narrative resolution lemmas ($T$) are disjoint ($P_{\text{clues}} \cap T = \emptyset$).

#### Pass 3: Deterministic Sealing & Atomic Emission

1. **RFC 8785 Canonical Serialization (JCS)**: Normalizes the validated in-memory world model to Unicode NFC, normalizes line endings to POSIX (`\n`), and sorts all object keys in lexicographical UTF-16 code unit order.
2. **Universal State Hashing ($H_{\text{root}}$ & $H_{\text{entity}}$)**: Computes a global SHA-256 Merkle root digest over the JCS-serialized output, along with individual entity hashes for dependency tracking:
  $$
  H_{\text{root}} = \text{SHA-256}(\text{RFC8785\_Canonicalize}(\text{BibleState}))
  $$
3. **Atomic POSIX Sibling Inode Swap**: Writes the serialized payload to an ephemeral sibling file (`compiled/<seriesSlug>/bible-state.json.tmp_[UUID]`) on the same disk mount, and replaces the active file via `fs.renameSync` to avoid partial writes.
4. **Dual-Emission Protocol**:
  - Emits the active canonical snapshot: `compiled/<seriesSlug>/bible-state.json`.
  - Emits the immutable historical WORM archive: `compiled/<seriesSlug>/bible-state_<YYYY-MM-DDTHH-mm-ssZ>.json` (using dashes to preserve cross-platform file system compatibility).
5. **In-Memory Immutability**: Applies recursive `Object.freeze()` to the resulting runtime model to prevent downstream memory tampering.
