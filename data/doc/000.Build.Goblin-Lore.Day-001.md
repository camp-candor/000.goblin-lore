A forensic analysis of the flattened snapshot `000.goblin-lore.txt` alongside the architectural specifications reveals the exact technical reality entering **Day 001**:

  - The core value proposition of `goblin-lore` is **preventive compilation at $T_0 = \$0.00$**—rejecting anatomically impossible, contradictory, or ungrounded fictional states before downstream LLM dialogue, TTS synthesis, or GPU rendering burn compute.

#### 1. Implement the Invariant Schema Core (`packages/299.lore/26.schema.unit` / `schemas/`)

[details](./001.invariant-Schema-Core.md)

- **Leverage Reason**: Downstream compilation cannot evaluate validity without typed contracts. Authoring Markdown frontmatter without formal Zod validation guarantees schema drift.
- **Concrete Deliverables**:
  - **Tripartite Character Vector**:
    - *Somatic Vector*: `locomotion_baseline` (enum), `available_arms` (float scalar), motor bounds, and `banned_kinetic_verbs: string[]`.
    - *Logistical Vector*: Capacity scalars, slot declarations (`worn`, `held`, `carried`, `cached`), and `weight_class` enforcement.
    - *Epistemic Vector*: `escalation_ceiling`, `leverage_strings`, and `refusal_vectors` ($\langle \text{Trigger}, \text{MandatoryRefusal}, \text{UnavoidableCost} \rangle$).
  - **Spatial Topology Schema**: Room capacities, acoustic damping decibel falloff ($c\text{dB}$), and bidirectional `adjacent_to` portals.
  - **Dual-Rail Grievance Schema**: Basis-point intensity ranges ($[I_{\min}, I_{\max}]$), cooldown tick quotas, causal DAG spawn triggers (`spawns_on_max_escalation`), and primary dyadic participant sets.
  - **Unresolved Canon Schema**: Forbidden resolution trigger lemmas ($T$) vs. permitted physical clue tokens ($P_{\text{clues}}$).

#### 2. Build the Offline 3-Pass Compiler & Gate 0 Gauntlet (`scripts/compile.ts`)

- **Leverage Reason**: The entire studio architecture depends on `bible-state.json` as a single, byte-identical source of truth consumed read-only by `worker-sower-engine` and `goblin-viewport`.
- **Compiler Passes to Wire Up**:
  - **Pass 1 (Invariant Evaluation)**: Parses Byte-0 YAML frontmatter from Markdown files using Zod; validates scalar limits ($0.0 \le s \le 1.0$), non-negative carrying mass, and anatomical slot capacities.
  - **Pass 2 (Relational DAG & Referential Integrity)**: Enforces that every participant, item, and adjacent room ID resolves to an active entity; evaluates the **Clue-Lemma Disjointness Theorem** ($P_{\text{clues}} \cap T = \emptyset$); runs cycle detection on grievance causal chains to prevent infinite loops.
  - **Pass 3 (RFC 8785 Canonical State Sealing)**: Strips non-deterministic timestamps (`new Date().toISOString()`), recursively sorts object keys alphabetically, computes a root SHA-256 Merkle hash ($H_{root}$), and atomically writes to `compiled/bible-state.json`.
  - **CLI Command**: Package into a single zero-exit Gate 0 command: `npm run lore:compile` / `npm run check:all`.
